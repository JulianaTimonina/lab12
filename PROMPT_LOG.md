reports/routes.py: /daily-summary (фильтр по датам, сумма выполненных заказов), /driver-performance (количество и сумма завершённых заказов по водителям) – только admin.

driver/dashboard.html (список своих заказов, кнопки действий по статусу).
admin/dashboard.html (ссылки).
admin/drivers.html (таблица + модальное окно для CRUD).
admin/tariffs.html (таблица + модальное окно).
admin/reports.html (выбор дат, таблицы).

main.js: fetchWithAuth с авто-выходом при 401/422.

### Промпт 4

**Инструмент:** DeepSeek

**Промпт:**
```
Измени логику работы водителя в приложении такси.
Текущее поведение: водитель в GET /orders видит только свои заказы, администратор вручную назначает заказы.
Новое поведение:
Водитель должен видеть все заказы без назначенного водителя (pending, driver_id IS NULL) и свой активный заказ (если есть).
Водитель сам назначает себя на свободный заказ через новый эндпоинт PATCH /orders/<id>/take.
При взятии заказа проверяется, что у водителя нет другого активного заказа (статусы assigned, accepted, in_progress).
После завершения заказа водитель становится доступным.
Обнови файлы orders/routes.py и templates/driver/dashboard.html соответственно.
```

**Результат:** Реализована новая логика, водитель видит свободные заказы и может брать их, пока не завершит текущий. Кнопки действий вынесены в блок активного заказа.
